# Battery and Fans

Lightweight Windows x64 battery and performance tray monitor, with a Vietnamese interface.

- Battery percentage in the tray icon.
- Battery discharge or charge power, remaining capacity and battery wear when supplied by the driver.
- Estimated time and clock time to empty or full, based on recent power measurements.
- CPU, RAM and GPU utilization.
- Translucent popup with pinning, movement and adjustable height.
- Optional startup at Windows sign-in.

The project name is historical. Version 1.6 contains battery and performance monitoring.

## Build

On Windows x64 with .NET Framework 4.x, run `powershell -File .\build.ps1` from the repository directory. The executable is written to `dist\Battery and Fans.exe`. GitHub Actions also builds each push and pull request. Download its unsigned build artifact from the Actions run.

The uploaded source is version 1.6.0.0. The original custom app.ico was unavailable when this public source was prepared, so this build uses the compiler's default executable icon. The dynamic percentage tray icon is generated by the application.

## Use

Run the executable. Left-click its tray icon for details and right-click for options. Pin the popup and drag its title to reposition it. Drag the bottom handle to resize. Startup is opt-in.

Estimates change with load and charging taper. Windows may sleep or shut down before the estimated empty time. Missing driver data appears as a dash.

## Privacy and system changes

All monitoring is local. Normal operation makes no network requests. The optional `--diagnostics <path>` command writes hardware readings to a local file selected by the caller.

Panel preferences are stored under `HKCU\Software\PinVaHieuNang`. The startup option writes or removes the `PinVaHieuNang` value under `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.

## Uninstall

Turn off startup in the tray menu, choose Exit and delete the executable. To remove saved preferences, delete `HKCU\Software\PinVaHieuNang` using Registry Editor. If the executable was already deleted, remove its `PinVaHieuNang` startup value from the Run key described above.
